사건·발표 시점 2026-10-29 02:00 KST 공식 소개문 공개. 일반 개발자·소비자 배포는 추후 예정.
확인한 최초 발표·보도 및 공개 근거 시각 2026-10-29 02:00 KST — Google 원문 datePublished 10월 28일 17:00 UTC. 이후 수정 시각과 구분.

Google은 Gemini 4 Carbon을 새 프런티어 모델로 소개하며 코딩, 장시간 과제 수행, 멀티모달 이해와 과학·사이버 분야의 역량 향상을 주장했다. 초기 접근은 Fairwind 프로그램을 통한 일부 사이버 방어 조직과 신뢰 파트너에 제공된다. 회사는 일반 개발자·기업·소비자 대상 제공을 앞으로 확대한다고 밝혔으므로, 이번 발표를 즉시 사용할 수 있는 일반 공개 API의 출시로 해석할 수는 없다.

개발 관점에서 중요한 변화는 높은 역량을 주장하는 모델의 공개가 안전성 검토 및 제한된 사용 경험 축적과 함께 진행된다는 점이다. 소개문의 사이버 벤치마크는 회사가 제시한 평가이며 일부 결과는 보호 장치 없는 조건을 사용한다. 따라서 실서비스의 안전성이나 모든 업무에서의 우위를 그대로 뜻하지 않는다. 비전·영상 편집을 포함한 자신의 입력 유형에서 품질, 지연, 비용을 비교할 수 있는 공개 접근과 재현 자료가 다음 판단 근거다.

왜 중요한가

후속 API 도입 계획과 자체 멀티모달 평가 설계에 직접 영향을 주는 모델 발표다. 현재 접근 가능 범위를 먼저 확인해야 한다.

앞으로 지켜볼 추가 신호

일반 API 공개일, 모델 카드·평가 데이터, 독립 벤치마크, 실제 이미지·영상 입력의 제한과 도구 호출 안정성.

사건·발표 시점 2026-10-28 연구 발표·논문 공개. 시뮬레이션 수행의 개별 날짜는 미공개.

MoI-Bench는 모바일 이미지 생성·편집을 평가하기 위해 64개 세부 과제와 1,150개 샘플을 구성했다. 삭제·교체 같은 16개 연산과 인물·문자 등 8개 시각 대상 범주를 나누고, 지시 준수·시각적 품질·세부 보존을 평가하는 MoI-Eval을 제안한다. 저자들은 단일 종합 점수 대신 품질과 기기 배포 적합성을 두 축으로 놓아 소형 모델과 서버 모델의 강점·약점을 비교했다.

AMARO v2.0은 무거운 원자를 모두 유지하면서 용매를 암묵적으로 처리하는 신경망 퍼텐셜이다. 수소 정보를 반영한 비드 유형과 총전하 조건을 이용해 단백질·약물 유사 분자·삼자 복합체를 함께 표현한다. 저자들은 11개 표적의 262개 복합체에서 대부분의 리간드 자세를 보존했다고 보고했다. 특정 trypsin–benzamidine 비교에서는 추정 GPU 시간 예산을 맞췄을 때 결정 결합 자세에 도달한 궤적 수가 3.3배 많았다.

이 결과는 모든 분자동역학 계산이 3.3배 빨라진다는 뜻이 아니다. 논문은 일부 결합 자유에너지가 실험보다 지나치게 유리하고, SHP2와 CDK8에서 자세 복원 또는 결합 부위 특이성의 한계가 남는다고 명시한다. 화학 개발자에게는 구조 예측 이후 복합체의 이동과 결합 사건을 통합 모델로 탐색할 가능성이 중요하다. 실제 화합물 우선순위 결정에 쓰려면 프로톤화 상태와 희귀 사건, 자유에너지 편향을 별도 검증하는 과정이 필요하다.

왜 중요한가

정적 복합체 구조를 넘어 동역학과 결합 사건을 다루는 AI for Science의 적용 범위와 현재 한계를 함께 보여준다.

앞으로 지켜볼 추가 신호

미지 화학종의 외삽, 프로톤화 상태 처리, 자유에너지 보정, 장시간 안정성과 실제 GPU 비용, 독립 표적에서의 재현.
