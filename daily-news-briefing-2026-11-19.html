Google, Gemini 4 Neon 공개…성능과 추론 비용을 함께 겨냥

AI · 멀티모달 모델 / API
사건·발표 시점 모델 공개·유료 접근 확대: 2026-11-19 06:00 KST. 계정별 실제 제공 시점은 순차 적용.
확인한 최초 발표·보도 및 공개 근거 시각 Google 공식 글 datePublished: 2026-11-19 06:00 KST(11/18 21:00 UTC).

Google이 Gemini 4 Neon을 공개하고 Gemini API 유료 이용자와 일부 유료 제품에 제공하기 시작했다. 공식 설명은 최대 100만 토큰 문맥과 문서·차트·오디오·영상 처리를 강조한다. API 가격은 100만 토큰당 입력 3달러, 캐시 입력 0.15달러, 출력 15달러다. 네 단계 사고 수준 중 기본값은 high이며, 더 높은 xhigh 설정을 별도로 제공한다. 모든 무료 이용자에게 같은 조건으로 즉시 배포되는 발표는 아니다.

개발 관점에서는 최고 점수보다 사고 설정, 캐시 적중률, 도구 실행 환경을 함께 비교하는 것이 핵심이다. Google이 제시한 순위와 비용 절감 수치는 특정 평가·설정의 결과이며 이 브리핑에서 독립 재현하지 않았다. 긴 영상이나 화학 문서 묶음을 다루는 시스템은 정답률뿐 아니라 첫 응답 지연과 전체 토큰 비용을 재측정할 필요가 있다. 보안 전문가용 별도 변형은 향후 제한 제공 계획이므로 현재 일반 API 모델과 구분해야 한다.

왜 중요한가

영상·문서 이해 기능과 실제 운용 비용을 함께 비교할 새 선택지가 생겼다. 기존 워크플로의 대표 입력으로 평가할 가치가 크다.

앞으로 지켜볼 추가 신호

한국 계정의 실제 모델 접근, 모델 ID와 제한, high/xhigh별 지연·비용, 장문 영상의 근거 추적 정확도, 독립 벤치마크 재현.

신뢰도

높음
모델 공개·가격·지원 범위는 Google 공식 자료로 확인했다. 성능 순위와 절감률은 발표자 평가이며 모든 작업에 일반화하지 않았다.

AI 모델 기업의 연구비와 추론 인프라 비용이 공개 자본시장의 평가를 받는 국면이라는 점이 중요하다. 다만 주당 공모가, 상장 후 시가총액, 완전희석 기업가치는 서로 다른 수치다. 기존 투자설명서의 주식 수에 83달러를 곱해 최종 조달액을 단정하면 증액이나 별도 투자분을 잘못 반영할 수 있다. 개발자에게는 주가 전망보다 자금 조달 이후의 API 가격, 서비스 약정, 인프라 투자와 수익성 공시가 직접적인 관찰 대상이다.

왜 중요한가

주요 AI 기업의 자금 조달과 비용 공개가 모델 경쟁 및 서비스 지속성 판단에 영향을 준다.

효소대체요법으로 접근하기 어려웠던 중추신경계 증상에 저분자 약물의 분포 특성이 기여한 사례다. 분자 설계 관점에서는 표적 결합력뿐 아니라 뇌 노출과 장기간 안전성까지 통합해 최적화해야 한다는 의미가 있다. 다만 작은 희귀질환 임상의 결과를 다른 신경계 질환이나 모든 환자의 회복으로 확대할 수는 없다. 공식 자료에는 정신과적 위험, 소아 수정체 혼탁 가능성과 배아·태아 독성에 관한 주의 사항도 있어 효능과 함께 읽어야 한다.

교육부와 행정안전부가 수능 당일 AI를 이용한 부정행위를 예방·적발하기 위해 전국 위급재난문자를 발송하고, 첫 발송 이후에도 불시에 추가 발송할 계획을 알렸다. 1차 예정 시각은 19일 오전 8시 30분이다. 정부 설명상 수신 거부가 되지 않으며 전원이 켜진 휴대전화에서 최대 볼륨으로 10.5초간 경보가 울린다. 이번 항목은 앞선 안내의 단순 반복보다 18일에 구체화된 불시 추가 운영 계획에 초점을 맞췄다.

Spool은 attention과 선형 순환 계층을 함께 쓰는 비전언어모델에서 최근 일정 시간의 영상만 유지하는 문제를 다룬다. 오래된 프레임을 제거할 때 전체 구간을 다시 실행하는 대신, 프레임별 상태 변환을 저장하고 결합하는 학습 없는 추론 방식을 제안한다. 저자들은 5개 공개 하이브리드 VLM과 4개 영상 추론 벤치마크에서 p95 첫 토큰 지연을 두 vLLM 기준 중 빠른 쪽보다 기하평균 6.6배 줄이고 평균 정확도를 2.3%포인트 높였다고 보고했다.

분석 장비마다 얻을 수 있는 신호가 다르거나 일부 측정이 빠진 연구 환경에서 여러 모달리티를 유연하게 합칠 수 있다는 점이 유용하다. 그러나 계산 데이터에서의 복원율을 실제 혼합물이나 큰 약물 분자 구조 규명 성공률로 옮길 수는 없다. 용매·온도·장비 응답과 같은 실험 조건이 바뀌는 경우도 별도 검증이 필요하다. 실무적으로는 생성한 구조를 정답으로 채택하기보다 추가 실험 후보와 스펙트럼 일치 검사의 우선순위를 만드는 도구로 평가할 만하다.

이 논문은 분자의 전자계와 과감쇠 극성 용매를 함께 다루는 양자–고전 동역학 밀도범함수 틀을 제안한다. 용매를 반응장 좌표로 나타내고 Ehrenfest–Smoluchowski 방정식으로 열평형 접근과 비평형 스펙트럼을 연결한다. 저자들은 자유에너지가 증가하지 않고 상세균형을 유지하는 성질을 제시했다. 클로로포름·디클로로메탄·DMSO 속 극성 염료의 이준위 모델에 적용해 흡수와 시간 분해 방출, 동적 Stokes 이동을 계산했다.

연구자에게 중요한 점은 용매 효과를 정적인 보정값으로만 두지 않고 시간에 따른 완화와 스펙트럼 폭 변화로 연결한다는 것이다. 저자들은 계산 결과가 세 용매의 실험적 이완 경향과 잘 맞는다고 보고했지만, 복잡한 반응계나 실제 신약 분자의 전자 상태를 포괄 검증한 것은 아니다. 여기서 제안하는 동역학적 용매 분포 틀을 통상의 정적 전자구조 DFT 계산과 동일하게 취급하지 않아야 하며, 적용할 계의 과감쇠 가정과 축약 좌표의 유효성을 먼저 살펴야 한다.

왜 중요한가

분광 신호와 용매 동역학의 연결을 물리적으로 일관된 방식으로 다루려는 계산화학 접근이다.
