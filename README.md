# 뉴스 브리핑

AI 개발자와 화학 분야 연구자를 위한 한국어 뉴스 아카이브입니다. 국내·국제·경제 흐름과 함께 AI 모델, 컴퓨터 비전, 기술, 화학·소재 및 관련 논문을 다룹니다.

## 뉴스 읽는 방법

1. 아래 목록에서 원하는 날짜의 HTML 파일을 선택합니다.
2. GitHub 파일 화면의 **Download raw file** 버튼으로 내려받습니다.
3. 내려받은 HTML을 브라우저에서 엽니다. 별도 프로그램 설치나 서버 실행은 필요하지 않습니다.

전체 날짜를 받으려면 저장소의 **Code → Download ZIP**을 이용하고 압축을 해제한 뒤 원하는 HTML을 여세요. 이전 날짜로 이동하는 링크를 사용하려면 관련 HTML을 같은 폴더에 보관하세요.

GitHub의 파일 화면에서는 뉴스 대신 HTML 소스가 보일 수 있습니다. 다운로드 없이 웹페이지로 공유하려면 별도로 GitHub Pages를 활성화해야 합니다. 이 README 자체가 Pages 활성화나 배포 완료를 의미하지는 않습니다.
