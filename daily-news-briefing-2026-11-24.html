Z.ai가 GLM‑5.4를 Coding Plan, ZCode, Z.ai Chat에 제공했다. 공식 설명은 기존 GLM‑5의 층을 반복 활용하는 Loop Transformer와 강화된 시각·코딩 능력을 핵심으로 제시한다. Coding Plan에는 100만 토큰 컨텍스트와 시각 입력이 표시됐고, V2·V3·팀 요금제의 해당 모델 사용 한도는 1.5배로 안내됐다. 일반 모델 API는 ‘추후 제공’, 가중치는 안전성 보강 후 공개 예정이므로 현재 내려받아 운영할 수 있는 모델로 소개해서는 안 된다.

해석: UI 스크린샷을 코드 수정에 연결하거나 CAD·3D 작업을 코드로 수행하는 개발 흐름에 의미가 있다. 회사가 보여 준 영상 편집·게임·FreeCAD 시연은 코드 활용 범위를 넓힌 사례이며, 독립적인 영상 생성·인페인팅 성능 평가와는 다르다. 더 큰 모델과 유사한 지능이라는 주장도 회사 평가다. 실제 도입 때에는 반복 추론이 주는 정확도 이득과 응답 지연, 장시간 사고 루프의 빈도를 같은 과제에서 비교할 필요가 있다.

왜 중요한가

시각 자료를 다루는 코딩 에이전트의 선택지가 늘었지만, 현재 접근 경로와 향후 공개 계획을 구별해야 한다.
