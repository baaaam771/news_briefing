Google은 Gmail·Drive·Docs·Sheets·Slides·Calendar·Chat·Tasks에 연결하는 관리형 MCP 서버와 공식 Workspace CLI를 정식 제공한다고 발표했다. 에이전트의 기존 REST API 직접 접근을 MCP 기반 경로로 전환하는 규칙은 2027년 2월 1일부터 기술적으로 시행한다. 사용량은 무료 Standard와 높은 한도를 위한 Scaled로 나뉘며, Gmail·Drive·Calendar API 및 MCP의 Scaled 무료 허용량 초과분 과금은 2027년 4월 1일 시작한다. 오늘 즉시 모든 REST API를 폐지하거나 모든 개발자에게 요금을 부과한다는 발표는 아니다.

해석: 문서·메일에 접근하는 개발 도구의 경쟁 조건이 모델 성능뿐 아니라 데이터 소유자의 접속 정책으로 이동한다. Google은 OAuth에서 에이전트를 식별하고 DLP·감사 로그·민감한 작업 확인을 연결하며, AI Tools Addendum에 일부 파생 데이터의 장기 보관 및 스크래핑 제한을 담았다. 사내 연구 에이전트도 호출 경로, 에이전트용 OAuth 클라이언트, 보관 방식, 할당량을 함께 점검할 필요가 있다. 내부 사용 예외는 문서별 적용 범위가 있으므로 MCP와 REST의 한도 예외를 동일하게 취급해서는 안 된다.

왜 중요한가

Workspace에 연결된 AI 서비스는 2월의 접속 경로 변경과 4월의 요금·한도 변경을 별도 일정으로 준비해야 한다.

SenseTime은 이해와 생성을 결합한 8B 모델 SenseNova U1.6에 이미지 자기수정 기능을 추가하고 가중치를 공개했다. 같은 모델이 초안을 생성한 뒤 원래 프롬프트와 그림을 비교해 발견한 글자 문제를 수정한다. 회사는 U1.6 Lite의 UltraTextBench 점수가 단일 생성 86.04에서 자기수정 사용 시 92.28로 올라갔다고 보고했다. 이는 약 7%의 상대 향상이며, 이전 모델 대비 7% 향상이라는 뜻은 아니다. 별도로 제시한 미적 평가 약 10% 향상은 U1.5 Lite와 비교한 내부 사용자 평가다.

해석: 포스터·도식 제작에서 생성 이후 OCR 검사와 재편집을 연결하는 작업을 모델 자체 흐름에 넣으려는 시도다. 공식 Hugging Face 모델 카드에는 Apache 2.0 라이선스와 BF16 체크포인트가 표시돼 있고, 이미지 편집·자기수정에는 대응하는 U1.6 실행 코드가 필요하다고 명시한다. 다만 Lite 서비스의 점수를 공개 8B 체크포인트의 독립 성능으로 옮겨 해석할 수 없다. 한국어·화학식·축 라벨처럼 오류 비용이 큰 출력에서는 수정 성공률과 수정 과정에서 새로 생긴 오류를 따로 측정해야 한다.

왜 중요한가

사용자의 이미지 생성·인페인팅 업무에서 생성→검사→수정 흐름을 직접 실험할 수 있는 공개 모델 후보가 추가됐다.

Lobals(Look Back in the Latent Space)는 멀티모달 언어모델에서 시각 토큰에 대한 주의가 강한 연속 계층 구간을 선택해 추론 중 다시 통과시키는 디코딩 방법이다. 저자들은 정상적인 생성을 유지하면서 재사용 가능한 계층이 존재하는지 확인하고, 이를 시각 증거를 다시 검토하는 잠재 공간 계산으로 활용했다. 추가 학습 없이 일반 비전·언어 과제, 시각 환각 평가, 시각 중심 과제에서 성능 개선을 보고한다. 긴 텍스트 추론문을 더 생성하는 것과 다른 방식의 추론 시 계산 확장이다.

개발자 관점의 해석: 이미지 이해 오류를 줄이는 데 항상 새로운 학습 데이터나 대규모 재학습만 필요한 것은 아니라는 접근이다. 다만 계층을 재실행하는 만큼 지연·메모리·배치 효율에 영향을 줄 수 있고, 내부 계층과 attention에 접근해야 하므로 모든 상용 API에서 그대로 적용할 수 있는 기법은 아니다. 화학 도식·현미경 영상으로의 확장은 별도 실험 과제다. 모델과 추론 예산을 맞춘 비교에서 얻는 정확도 향상과 운영 비용을 함께 평가해야 실제 채택 여부를 판단할 수 있다.

왜 중요한가

컴퓨터 비전 에이전트에서 재학습 없이 시각 증거를 재검토하는 추론 경로를 실험할 수 있는 후보 방법이다.

앞으로 지켜볼 추가 신호

기반 모델별 적용성, 계층 선택 비용, 정확도 대비 지연·처리량, 시각 환각 감소의 외부 재현, 코드 공개와 라이선스.
