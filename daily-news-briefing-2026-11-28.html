샤오미가 AutoWorldModel 2.0을 발표하며 주행·로봇 환경의 영상, 행동, 카메라 자세와 공간 배치를 함께 다루는 모델 구성을 공개했습니다. 공식 프로젝트는 1~7개 카메라 시점과 시간축을 통합하고, WorldRec 2.0의 지속적인 3차원 맥락을 활용하는 방식을 설명합니다. 회사가 제시한 1,000회 폐루프 시뮬레이션에서 E2E-WM-RL의 충돌률은 0.4%, 비교한 ST-JEPA-E2E는 1.2%였습니다. 이는 회사의 특정 실험 설정에서 얻은 수치입니다.

Hugging Face의 David Corvoysier, Jingya Huang, Sayak Paul은 AWS Trainium3에서 LTX-2.5 영상 생성을 최적화한 과정을 공개했습니다. 글에 따르면 trn3.48xlarge의 64개 NeuronCore 가운데 32개를 사용해, 모델이 이미 적재된 상태에서 소리가 포함된 2048×1024 해상도 10초 영상을 약 22~23초에 생성했습니다. 텐서 병렬 4개와 시퀀스 병렬 8개를 조합하고, CPU 스레드·컴파일·메모리 복사·연산 정밀도와 디코더 실행을 조정한 결과입니다.

개발자가 참고할 부분은 단일 속도 숫자보다 CUDA 밖의 가속기로 모델을 옮길 때 마주치는 병목과 해결 과정입니다. 같은 글은 모델 적재에 약 3분, 첫 영상에 약 80초가 걸리는 조건도 설명하므로 22~23초를 처음부터 끝까지의 응답 시간으로 읽으면 안 됩니다. 초기의 더 작은 해상도·다른 코어 구성과 최종 결과도 동일 조건 비교가 아닙니다. 다른 GPU보다 비용이나 성능이 우월한지 판단하려면 같은 품질·배치·적재 조건의 비교와 실제 사용 요금이 필요합니다.

arXiv v1 제출 이력을 확인했습니다. 공개판은 열람했으나 최초 정기 배포 시·분은 별도 확정하지 못해 제출 시각과 공개 시각을 동일시하지 않습니다.

WeMM-Ecom은 전자상거래의 이미지·텍스트 이해에 맞춘 멀티모달 모델 계열입니다. 논문은 8억 매개변수의 밀집 모델부터 전체 350억·활성 30억 매개변수의 MoE 모델까지 다섯 규모를 설명합니다. 전자상거래 데이터 비중을 높이는 두 단계 지속 사전학습 뒤, 생각하기 방식의 증류와 강화학습을 결합합니다. 평가는 전자상거래 28개 과제와 일반 64개 과제를 사용하지만, 전자상거래 평가 중 23개는 내부 과제이므로 외부 비교 가능성에 제한이 있습니다.

개발자에게는 범용 모델을 단순히 미세조정하는 것보다 데이터 혼합 비율과 추론 방식, 도메인 평가를 함께 설계한 사례라는 점이 유용합니다. 소재 카탈로그나 분석 이미지에서도 이런 설계 원칙을 참고할 수 있으나, 논문이 화학 이미지의 정확도를 검증한 것은 아닙니다. 내부 벤치마크의 큰 비중을 고려하면 성능 주장을 그대로 도입 근거로 삼기보다 공개 과제의 재현과 사용자 자신의 분포에서 검증을 거치는 것이 필요합니다.

왜 중요한가

도메인 특화 멀티모달 모델의 데이터·후학습·평가 구성을 함께 검토할 수 있어 연구용 비전 모델 개발에도 참고할 수 있습니다.

앞으로 지켜볼 추가 신호

공개 가중치·코드로 재현되는 결과, 내부 과제의 공개 범위, 도메인 밖 성능 저하와 사용자 데이터의 오류 분석.
