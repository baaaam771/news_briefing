WINGS: Reference-Free Gaussian Splatting Inpainting with 3D-Native Generative Priors
저자: Noé Lallouet, Michael Fischer, Elie Michel
공개 기준: 2026-09-30 09:00 KST · arXiv 신규 공개 배치
arXiv 공식 신규 목록과 운영 일정에 따른 공개 배치 기준입니다. 개별 파일의 실제 공개 분·초는 직접 관측하지 않았습니다.

WINGS는 여러 시점의 2D 이미지를 각각 편집한 뒤 맞추는 대신, 기존 Gaussian splatting 장면의 빈 영역을 3D 생성 사전모델 TRELLIS의 잠재 표현에서 직접 채운다. 구조 완성 네트워크로 채울 공간을 정하고, 주변 장면 정보를 점진적으로 반영해 모양과 외관을 생성한다. 마지막에는 장면별 디코더 적응으로 새 Gaussian을 기존 장면에 맞춘다. 따라서 참조 이미지가 필요 없다는 뜻이지, 모든 구성 요소가 무학습이거나 장면별 최적화가 없다는 뜻은 아니다.

저자들은 동일한 장면과 3D 마스크를 사용한 29개 장면 실험에서 품질을 비교했다. 29명이 참여한 총 1,401회 쌍대 평가에서 Inpaint360GS 대비 동점 보정 승률은 75.11%였고, 단일 NVIDIA H100에서 평균 처리 시간은 176.8초였다. 다중 시점의 자연스러움은 유망하지만 즉각적인 실시간 편집은 아니다. 축에 정렬되지 않은 복잡한 무늬와 시점에 따른 반사 표현에는 한계가 남으며, 수치는 저자 자체 평가로 독립 재현 결과는 확인하지 못했다.

왜 중요한가

관심 키워드인 inpainting을 3D 장면 편집으로 확장한다. 여러 시점에서 일관된 배경을 복구해야 하는 디지털 트윈·3D 콘텐츠 작업에 검토할 만한 접근이다.

Persistence Forcing: Exploiting Feature Specialization in Pixel-Space Diffusion
저자: Chong Wang, Zixuan Fu, Shiqi Huang, Siyuan Yang, Hao Cheng, Bihan Wen
공개 기준: 2026-09-30 09:00 KST · arXiv 신규 공개 배치

PerF는 이미지를 압축 잠재공간이 아닌 픽셀 공간에서 생성하는 확산 Transformer의 내부 특징을 서로 다른 빈도로 갱신한다. 덜 자주 갱신하는 특징에는 전체 배치와 큰 형태를 유지시키고, 더 자주 갱신하는 특징에는 질감과 세부 묘사를 맡긴다. 전자의 정보를 후자에 계속 공급하는 Persistence Forcing과 추론 시 추가 유도를 결합한다. 단순히 네트워크 폭만 다르게 하는 것이 아니라, 안정적인 전역 구조가 국소 디테일 생성을 이끌도록 설계한 방법이다.

공개 기준: 2026-09-30 09:00 KST · arXiv 신규 공개 배치
arXiv 공식 신규 목록과 운영 일정에 따른 공개 배치 기준입니다. 개별 파일의 실제 공개 분·초는 직접 관측하지 않았습니다.

CrystAF는 분자 결정 생성기에 물리 정보를 언제 넣는 것이 유리한지, 같은 생성 모델과 UMA 원자간 포텐셜을 사용해 비교한다. 완화된 구조를 학습 표적으로 쓰는 방법, 물리적 선호를 후학습하는 방법, 생성 후 추론 단계에서 완화하는 방법을 구분했다. 200개 검증 계열에서 계열당 20개 구조를 생성한 32회 모델 평가 조건에서, 맞춘 비교쌍의 분자 기하 타당성(PoseBusters) 통과율은 89.32%에서 92.02%로 높아졌다. 단일 L40S에서 평균 생성 시간은 표본당 396ms와 398ms로 비슷했다.

OFoldNA: 핵산의 염기쌍 정보를 결합한 AlphaFold 계열 구조 예측

Leveraging secondary-structure information for accurate nucleic acid structure prediction with OFoldNA
저자: Valhalla Team
공개 기준: 2026-09-30 09:00 KST · arXiv 신규 공개 배치
arXiv 공식 신규 목록과 운영 일정에 따른 공개 배치 기준입니다. 개별 파일의 실제 공개 분·초는 직접 관측하지 않았습니다.

OFoldNA는 AlphaFold3 계열의 Protenix 구현에 핵산의 염기쌍 관계를 표현하는 입력과 보조 예측 모듈을 더한 전원자 확산모델이다. 외부 2차 구조 없이 예측하는 모드와 외부 2차 구조를 받아 3차 구조로 연결하는 모드를 구분하고, 부분적인 염기쌍 정보도 활용한다. 저자 FoldBench 평가에서 외부 2차 구조를 주지 않은 경우, 핵산 길이 20개 이상인 단백질–DNA 접촉면 58개의 평균 DockQ는 0.286으로 비교한 AlphaFold3의 0.238보다 높았다. 모든 분자·조건에서 앞선다는 결과는 아니다.

특히 더 큰 개선을 보인 OFoldNA-SS2TS 실험에는 정답 3차 구조에서 추출한 염기쌍 지도가 입력된다. 이를 외부 구조 정보 없이 예측한 성능과 혼동하면 안 된다. 염기쌍 측정·예측 오류의 영향, 제한적인 평가 표본, 용액·이온 조건에 따른 구조 변화를 따로 확인해야 한다. 공식 저장소는 코드를 2026년 10월경 공개할 예정이라고 안내하며 조사 시점에 실행 구현을 확인하지 못했다. 논문 공개를 즉시 사용 가능한 모델 배포나 독립 재현 완료로 보지 않았다.

왜 중요한가

AlphaFold 유사 모델의 다음 발전 방향을 서열·3D 구조뿐 아니라 측정 가능한 중간 구조 정보의 결합에서 보여준다. 핵산–단백질 복합체와 구조 제약 기반 설계에 직접 관련된다.

  • 논문은 제출 시각이 아니라 공식 공개 배치를 우선했습니다. 개별 실제 공개 분·초는 확인하지 못했습니다. 프리프린트·저자 성능 주장·학회 채택 표기는 독립 재현이나 임상·상용 검증과 다릅니다.
  • 높음은 발표·배포·통계 등 해당 사실의 근거가 강하다는 뜻입니다. 보통은 자체 평가·초기 연구·시각·접근 범위의 제한이 남는 경우입니다. 무오류나 장래 성과를 보증하는 등급은 아닙니다.

  • CSS·스크립트·본문은 이 파일 안에 포함됩니다. 단독 HTML 열람에는 서버가 필요 없고 원문 방문에는 인터넷이 필요합니다. 구조·내부 링크·검색·필터·테마 로직은 검사했으며, 브라우저 접근 제한으로 실제 화면 렌더링 검사는 수행하지 못했습니다.
