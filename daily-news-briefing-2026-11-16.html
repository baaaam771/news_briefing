llama.cpp를 수정하는 독립 프로젝트 tandem.cpp의 v0.3.0 변경 기록은 MoE 모델의 프롬프트 처리 배치를 512토큰에서 4,096토큰으로 키우는 방식을 설명한다. 긴 입력을 처리하는 동안 전문가 캐시의 VRAM 일부를 임시 버퍼에 빌려주고, 응답 생성 단계에서 되돌리는 구조다. 개발자는 RTX 5070 Ti 16GB와 RAM 64GB의 특정 Qwen3.8 시험에서 5.5천 토큰 입력의 첫 응답 대기시간이 이전 버전 12.4초에서 4.1~7.0초로 줄었다고 보고했다.

이 결과는 모델 전체가 VRAM에 들어가지 않는 개인용 PC의 메모리 이동 비용을 줄이는 데 초점이 있다. 커널 성능만 비교하는 대신 프롬프트 길이, RAM·SSD 상태, 전문가 캐시 크기를 함께 봐야 한다는 사례다. 제시한 수치는 개발자 자체 측정으로, 다른 GPU나 동시 사용자 서비스에서 같은 배율을 기대할 근거는 없다. 프로젝트는 ggml-org와 별개이며 고정된 기반 커밋을 사용한다. 최신 upstream 변경과의 호환성, 메모리 부족 회귀 여부도 따로 확인해야 한다.

왜 중요한가

재정경제부는 이형일 부총리가 15일 오후 4시 30분 관계부처 장관과 청와대 정책실장 등이 참석한 경제현안간담회에서 물가 관리 방안을 논의했다고 발표했다. 정부는 부처 간 추가 협의와 각계 의견 수렴을 거쳐 방침을 확정할 계획이라고 설명했다. 연합뉴스는 이미 3일 발표된 10월 소비자물가 상승률 2.8%를 회의의 배경으로 제시했다. 오늘 새롭게 확인된 사실은 회의 개최와 후속 협의 방침이며 새로운 물가 통계 발표는 아니다.

Are Scaling Laws of Universal MLIPs Universal?
저자: Theo Keane, Anthony Onwuli, Richard Tomsett, Robert M. Forrest, Jonathan J. Bean
공개 기준: 최근 7일 보충 · 11월 13일 공개 목록(원문 일자) · 제출 11월 12일 00:19:52 KST
arXiv 2026-11-13 신규 공개 목록 기준. 제출일과 공개 목록일은 구별했으며, 개별 최초 공개 시각은 미제공.

연구팀은 M3GNet·MACE·PET의 모델 구성을 고정하고, MatPES-MP-ALOE 통합 데이터에서 1만~64만 구조의 부분집합 및 전체 116만 구조를 이용해 학습 규모 효과를 비교했다. 무작위 표집, 화학·구조별 층화, 다양성 중심 선택 등을 평가한 결과 오차 감소의 지수와 표집법의 순위가 모델·목표 물성·시험 데이터 분포에 따라 달라졌다. 어떤 화학 층화 방법은 다른 분포로 옮겼을 때 개선되면서 원래 분포에서는 오히려 나빠지는 경우도 있었다.

계산화학·소재 연구에서 DFT 데이터를 더 생산할 때 단순한 구조 개수보다 실제 적용할 화학 공간을 얼마나 잘 덮는지가 중요하다는 해석이다. 학습 데이터와 시험 데이터의 화학적 차이가 손실과 강하게 연결됐다는 관찰은, 예산을 새 원소 조합이나 특정 결함·상태에 배정할 근거를 찾는 데 유용하다. 그러나 모든 표집 방법의 보편적 우열을 정한 연구는 아니다. 자신의 촉매·전해질·계면 문제에 맞춘 외부 시험 세트를 먼저 정의하는 것이 관건이다.

왜 중요한가

비싼 양자화학 데이터 생성 예산을 어디에 쓸지 결정할 때 단일 스케일링 곡선에 의존하는 위험을 보여준다.

앞으로 지켜볼 추가 신호

촉매·액체·계면에서의 재현, 목표 물성별 표집 정책, 계산 비용을 포함한 실제 데이터 효율.
