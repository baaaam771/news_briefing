확인된 사실은 ComfyUI와 vLLM, LiteLLM 등 실행 도구의 새 배포가 이어졌다는 것이다. 이를 지원 모델까지 모두 이날 처음 등장한 것으로 해석하지 않았다. 로컬 체크포인트와 외부 파트너 API, 추론 서버와 요청 게이트웨이는 서로 다른 층의 변화다. 개발자에게 중요한 해석은 새 이름을 목록에 추가하는 것보다 기존 워크플로가 재현되는지, 데이터가 어디로 나가는지, 의존성과 비용이 어떻게 달라지는지를 확인해야 한다는 점이다. 특히 재료·현미경 이미지에는 정확성뿐 아니라 원본의 기밀성도 걸린다. 이번 발표들 사이에 공동 개발이나 직접적인 인과관계가 있다는 뜻은 아니다.

ComfyUI가 이미지 생성 작업 흐름을 구성하는 도구의 안정판 0.42.0을 공개했다. 공식 변경 목록에는 MOSS-image 네이티브 지원과 Krea 3 Image 파트너 노드가 포함됐다. MOSS 관련 원문은 체크포인트 인식, 전용 구조와 텍스트 인코더, LoRA 연결을 설명한다. 따라서 이번 소식의 핵심은 새 모델을 처음 발표했다는 것이 아니라, 앞서 공개된 모델·API를 정식 버전의 작업 흐름에서 연결할 수 있도록 배포 단위를 갱신했다는 점이다.

MOSS 지원은 로컬 체크포인트를 불러오는 경로이고, Krea 파트너 노드는 외부 API를 연결하는 경로여서 데이터 이동·비용·이용 조건을 같은 것으로 보면 안 된다. MOSS와 Krea 관련 코드는 각각 10월 16일과 15일 개발 브랜치에 먼저 병합됐으며 오늘의 집계 사건은 0.42.0 릴리스다. 기존 마스크·LoRA·후처리 파이프라인의 호환성을 확인할 가치가 있지만, 이 배포만으로 인페인팅 정확도나 생성 속도의 개선이 독립적으로 입증된 것은 아니다.

왜 중요한가

이미지 모델을 연구 코드에서 실제 반복 작업으로 옮길 때 로컬 실행과 외부 API를 동일한 노드 기반 흐름에서 비교하기 쉬워진다. 현미경·재료 이미지 실험에서는 원본 데이터 반출 여부를 경로별로 구분해야 한다.

vLLM이 추론 서버 안정판 0.32.0을 공개했다. 변경 목록에는 EmbeddingGemma 2의 멀티모달 임베딩, MiniCPM-V 4.7, Nemotron 3.5 ASR 등 이미 공개된 모델을 실행하는 지원과 비디오 입력 경로가 포함됐다. 또한 구조화된 상태에 대한 선택·점수화 요청을 처리하는 System One 엔드포인트와 체크포인트의 응답 템플릿을 읽는 공통 파서를 제시했다. 새 가중치 발표가 아니라 기존 모델을 서비스하는 런타임의 업데이트로 봐야 한다.

운영 측면에서는 CORS의 기본 허용 범위를 줄이고, 신뢰할 수 없는 이미지 형식의 처리와 멀티모달 공유 메모리 캐시를 강화하는 변경이 함께 들어갔다. 다만 Python 3.10 지원 종료처럼 배포 환경을 바꿔야 하는 항목도 있다. 음성 지원 역시 완성된 오디오의 전사와 실시간 스트리밍을 구별해야 하며, 릴리스가 후자를 모두 제공하는 것은 아니다. 성능 향상 수치는 프로젝트 측 측정이므로 사용자 데이터와 장비에서 지연·메모리·정확성을 다시 확인해야 한다.

왜 중요한가

사내 비전·문서·음성 모델을 외부 API 대신 직접 운영하는 팀에 모델 호환성과 보안 경계가 동시에 바뀌는 배포다. 과학 데이터의 긴 입력을 다룰 때 메모리만 줄이고 오류율을 놓치지 않는 검증이 중요하다.

배포 이미지와 Python·Transformers 의존성 호환성, 기존 클라이언트의 CORS 설정, 첫 토큰 지연과 메모리, 멀티모달 요청의 결과 일관성 및 후속 회귀 보고.

MAD-CORE: 17억 원자 구조에서 계층적으로 고른 학습용 핵심 집합

Hierarchical universal open structure dataset for atomistic modeling
저자: Sofiia Chorna, Cesare Malosso, Jonathan Schmidt, Michele Ceriotti · EPFL
공개 기준: 2026-10-16 09:00 KST · arXiv 신규 공지 배치 · 최근 7일 보충
공식 신규 공지 배치 기준 · 제출일 및 코드·데이터의 최초 배포일과 구분

MAD-CORE 연구는 서로 겹치고 계산 수준도 다른 원자 구조 데이터들을 어떻게 정리할지 다룬다. 약 17억 구조를 모은 MAD-COSMO에서 여러 원자간 퍼텐셜의 표현을 반영한 거리 척도를 만들고, 다양성이 높은 구조를 계층적으로 선택했다. 최종 핵심 집합은 16,777,216개이며 앞부분만 사용해도 더 작은 부분집합이 되도록 정렬된다. 모든 구조에 동일한 DFT 정답이 붙은 데이터가 아니라 구조·출처·모델 예측과 일부 재계산 참조값을 구분해 제공한다.

선정 결과의 94%가 3차원 벌크 물질이어서, 보편적인 화학 공간을 균등하게 대표한다고 해석하면 안 된다. 거리 척도와 원래 후보 풀의 편향이 선택에 영향을 준다. 공식 MAD-CORE 기록에는 실제 구조·특징 파일과 DFT 부분집합이 있으며 README도 확인했다. 기록은 CC BY 4.0이지만 원천 데이터별 라이선스·인용 의무는 별도다. 샘플링 코드와 ecumetric 모델 파일도 확인했으나, 전체 데이터를 내려받아 무결성이나 학습 성능을 재현한 것은 아니다.

왜 중요한가

새 분자·소재 모델의 데이터 규모를 늘리는 문제를 중복·다양성·라벨 일관성 문제로 나눠 볼 수 있다. DFT 계산 예산을 배분하는 출발점이 된다.

SNK: CPU의 벡터 연산을 활용해 전자구조 계산의 교환 행렬을 가속

Data-Driven Optimization of Seminumerical Exchange for SIMD CPUs
저자: Jesse DiCenso, Henryk Laqua, Martin Head-Gordon · University of California, Berkeley
공개 기준: 2026-10-16 09:00 KST · arXiv 신규 공지 배치 · 최근 7일 보충
공식 신규 공지 배치 기준 · 제출일 및 코드·데이터의 최초 배포일과 구분

이 연구는 대형 분자의 Hartree–Fock·하이브리드 DFT 계산에서 비싼 교환 행렬 구축을 CPU에 맞춰 최적화한다. 반수치 적분과 혼합 정밀도를 사용하고, SymPy로 만든 적분식을 공통 부분식 제거와 벡터 연산에 적합한 C++ 코드로 변환한다. 실제 실행 시간에 따라 적분 커널을 선택하는 데이터 기반 최적화이며 신경망 모델 출시는 아니다. 시험은 AVX-512를 지원하는 Threadripper 9960X의 24개 물리 코어를 주로 사용했다.

분자 캡슐의 cc-pVTZ 시험에서는 교환 행렬을 한 번 만드는 시간이 기존 4중심 적분 3,837.1초에서 SNK 38.7초로 약 99배 줄었다. 전체 전자구조 계산이 99배 빨라졌다는 뜻은 아니며, 작은 분자에서는 다른 근사법이 유리할 수 있다. 수치 격자에 따른 에너지 오차도 남는다. 계산은 Q-Chem 7.0.0 개발판에서 수행됐고, 공개 확인한 것은 MIT 라이선스의 적분 코드 생성기다. 힘·진동수·NMR 계산 확장은 향후 과제로 제시됐다.

왜 중요한가

분자 AI의 학습 라벨을 만들거나 후보를 양자화학으로 재검증할 때 CPU 비용이 병목인 팀에 관련성이 높다.

앞으로 지켜볼 추가 신호

정식 Q-Chem 제공 범위, 다른 CPU·분자계에서의 시간 및 정확도, 미분량 지원과 전체 작업 시간의 개선 폭.
